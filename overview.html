Layout & spacing

402 × 874 reference phone; 4 columns, 24 px margins, 12 px gutters. Use real device safe-area insets in implementation.

Spacing scale: 4, 8, 12, 16, 20, 24, 32, 40, 48, 56, 64 px. Main actions: 56 px high; compact targets: at least 48 px.

Responsive CSS

Phone <768: 4 columns, 24/12 px margin/gap; 16/8 at ≤360. Tablet ≥768: 8 columns, 32/16. Desktop ≥1200: 12 columns, 32/24, max width 1280 px.

Download responsive.css for media queries, safe areas, reduced motion and forced-colors rules.

Reusable components

Buttons and count controls use soft raised surfaces and a 120 ms inset press. States: default, focus, pressed, loading, disabled and selected.

Rounded two-tone SVG icon library; complete teacher/parent navigation; keyboard menus; labeled forms with inline errors; confirmation dialogs; bottom sheets; full-width message rows; search; empty states; summary and pickup-pass surfaces.

Tables serve documentation; teacher pickup uses focused lists. Component coverage distinguishes adaptations, missing artwork and retired designs.

Key interaction rules

  • Attention opens unresolved work. Count controls reveal remaining children or pickup history. Attention is a subset of Remaining.
  • Scan → compare guardian → explicit handoff confirmation. Swipes and QR scans alone never mark a child picked up.
  • Parent sharing starts explicitly and lasts one trip. Manual updates remain available. Approaching, arrived and picked up are separate states.
  • Tap an entire message to reply. Search highlights only the selected child. Summary claims link to source messages.

Accessibility & behavior

Visible focus, keyboard and tap alternatives to swipes, predictable dialog focus return, wrapping names/messages and labeled status colors. Honor reduced motion. Use ink for small text; sage is an accent.

Examples are isolated components, not application mockups. Camera, location, identity, messaging and AI integrations are outside this document.

Patterns & implementation

Persistent navigation, progressive disclosure, contextual replies, modal confirmation, search/filter, visible feedback, direct manipulation, journey progress and source-linked summaries.
