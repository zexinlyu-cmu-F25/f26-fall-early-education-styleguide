KIDDASH STYLE GUIDE · VANILLA HTML / CSS / JAVASCRIPT

Simplest: double-click kiddash-style-guide-offline.html.
It includes all fonts, graphics, CSS and JavaScript. No server is needed.
Alternatively, extract the full ZIP and open index.html with its assets beside it.

Optional local development server:
  python3 -m http.server 8080
Then open http://localhost:8080 . No package install or build step is required.
The CSS reference panels also work offline through guide-resources.js.

index.html       Interactive style guide and component demos
kiddash.css      Shared application tokens and component styles
responsive.css   Responsive, media-query and accessibility rules
guide.css        Documentation shell and specimen visualization styles
guide.js         Routing, working examples and local interaction state
overview.html    Printable one-page overview; Copy for Jama action
assets/          Official supplied logo, exported icon library, font files

Demonstrations use fictional data and reset on reload. No real camera,
location, school record, messaging, identity check or AI service is connected.
Swiping or scanning does not record a handoff. Confirm handoff is explicit.

Brand artwork: user-supplied kid-dash-logo-transparent.svg, unchanged.
Icons: existing Kiddash Figma component library, exported as SVG.
Font: Nunito Sans, distributed under SIL Open Font License; see assets/OFL.txt.
